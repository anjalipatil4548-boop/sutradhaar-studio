# Sutradhaar Studio — Creative Digital & WebGL Studio

> **Live Website:** [https://sutradhaar-studio.pages.dev/](https://sutradhaar-studio.pages.dev/)

**Sutradhaar Studio** is an interactive digital & creative development studio based in Mumbai, blending custom WebGL shaders, MSDF typography, bespoke showreels, and ultra-responsive motion design.

## Key Features
- **Interactive WebGL & MSDF Typography Engine:** Smooth 60 FPS GPU-accelerated type rendering and canvas transitions.
- **Case Studies & Portfolio Showcase:** Highlighting digital products, brand systems, and custom interactive experiences (`Saarthi`, `Aangan`, and flagship client engagements).
- **Performance-Optimized Static Build:** Pre-rendered Nuxt static routes, responsive `_ipx` imagery, and downscaled hero visuals (`1920x1080`) for fast first contentful paint.
- **Zero Hydration Mismatches & Clean Routing:** Verified static routes with SPA `404.html` fallback and CORS-ready asset headers.

## Tech Stack
- Nuxt.js Static Site Generation (SSG)
- WebGL / GLSL Custom Shaders & MSDF Font Rendering
- Prismic-backed Media Pipeline (locally bundled for offline/edge reliability)
- Deployed on **Cloudflare Pages**
